# Stajich Lab Website

Source for **[lab.stajich.org](https://lab.stajich.org)**, the website of the Stajich Laboratory for Fungal Evolutionary Genomics at the University of California, Riverside.

## Layout

- `_members/` - one page per lab member (current and alumni)
- `_posts/` - blog posts / lab news
- `_data/` - projects, publication sources, and role/type definitions
- `team/`, `research/`, `projects/`, `join/`, `contact/`, `blog/` - top-level pages
- `images/` - photos and graphics

## Built with

The site is based on the [Lab Website Template](https://github.com/greenelab/lab-website-template) (Jekyll, GitHub Pages, and Manubot for automatic citations). See the [template documentation](https://greene-lab.gitbook.io/lab-website-template-docs) for details on the available components.

## Posts written by AI

Add `ai-generated: true` to the front matter of any post whose text was written only by AI (for example, publication summaries). The post layout (`_layouts/post.html`) then shows a notice at the top of the post saying the summary was generated by AI. Remove the flag once a lab member has rewritten or reviewed the text.

## Publication thumbnails

Publications in `_data/sources.yaml` use a local figure from the paper when it is open access (CC BY), otherwise a stock silhouette from PhyloPic or Bioicons stored in `images/publication_images/icons/`. Credits and licenses for those icons are in `images/publication_images/icons/CREDITS.md`. Please keep that file up to date when adding icons, and avoid hotlinking publisher images because they stop working.
